# Scrollbrella

A calm home-screen web app to open instead of doom-scrolling: a soft background,
gentle prompts you can edit, and quiet piano.

Live: https://fulaibaowang.github.io/scrollbrella/ — open in Safari on iPhone,
then **Share → Add to Home Screen**.
